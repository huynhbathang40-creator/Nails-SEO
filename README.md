# GlowBack Landing Page

Landing page for GlowBack — more Google reviews for nail salons.

It's a single self-contained `index.html` with no build step.

## Deploy on Netlify

1. In Netlify, choose **Add new site → Import an existing project → GitHub** and pick this repo.
2. Leave the build command empty. Set the publish directory to `.` (`netlify.toml` already does this).
3. Click **Deploy**.
